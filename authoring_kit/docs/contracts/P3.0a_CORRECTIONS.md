## P3.0a — the nine corrections

### 1. Do not claim the kernel enforces proposer ≠ confirmer
- **Was:** `CONTRACT_AUTHORITY.md §5` — "`_validate_confirmation_actor` … enforces separation of duty";
  "proposer ≠ confirmer, genuinely."
- **Reality (`0b0245c`):** `_validate_confirmation_actor` (`authoring.py:2137-2148`) checks only that the
  confirmer **holds the target owner role** (`:2145`) **and an allowed confirmer role** (`:2147`) in the
  same workspace/client boundary — **role membership, not principal distinctness.** No proposer≠confirmer
  identity check exists.
- **Now:** frozen as **host-side human candidate ratification** — the host authenticates ratification via a
  **separate human confirmer session** and issues the confirmation credential only to it (unavailable to
  the drafting agent). `owak confirm` is preserved as the **execution path**. **Independent platform
  approval (activate/release) stays outside P3.**

### 2. State the credential paths accurately
- **Was:** implied credentials never transit the wire (`CONTRACT_IPC_WIRE.md §4` "to memory only").
- **Now:** `AdapterRequest`/`AdapterResponse` **never** carry a credential (in-process `trust=` only), **but
  the authority IPC necessarily transmits the exact `OperationCredential` transiently** — issuance
  (host→client) and `authenticate_actor` (client→host) — channel-protected, never logged/persisted.
  (`CONTRACT_AUTHORITY.md §2`, `CONTRACT_IPC_WIRE.md §1/§4`, `CONTRACT_CLI.md §5`.)

### 3. `advance_authority` hard-refuses and is off the wire allowlist
- **Reality (`0b0245c`):** `advance_authority` is called **only** during `install_authority` journal
  recovery (guard `authoring.py:3181`; call `:3196`), never in the authoring loop.
- **Now:** the authoring `AuthorityHostClient.advance_authority(...)` **hard-refuses**
  (`AuthorityAdministrationError`); `advance_authority` is **excluded from the authority wire allowlist**
  (allowlist = methods 1–8 + credential issuance); `owak` gains no `advance-authority` verb. Administration
  (install/rotate/advance) is a **separate administrative client and channel**.
  (`CONTRACT_AUTHORITY.md §2`, `CONTRACT_IPC_WIRE.md §1`, `CONTRACT_CLI.md §4`.)

### 4. Protected config is non-writable by the drafting principal
- **Was:** config "ACL-restricted to the drafting principal's control."
- **Now:** the drafting principal may **read but not write** the endpoint/pin config; only an
  **administrative identity** writes it. P3.1 verifies (best-effort) and treats a writable/absent config as
  a fail-closed `E_AUTHORITY_UNAVAILABLE`. (`CONTRACT_IPC_WIRE.md §3`.)

### 5. F1 = single-defect tests at the real refusal points
- **Was:** combined injections ("no source / no evidence"; "no eval / no owner") with hedged refusal points.
- **Now:** each F1 test injects **one** defect at its **real** refusal (`P3.0_CONTRACT_FREEZE.md §6`):
  - **Provenance** splits — dangling **source** (`validate`, `authoring.py:1580-1587`) and dangling
    **evidence** (`validate`, `:1588-1592`) are **separate** tests.
  - **Causal / applicability / abstention** refuse at **`propose`** via vnext model validators
    (`vnext.py:445-447` / `:227` / `:319,:824`).
  - **Lifecycle** refuses **immediately** (`_assert_candidate_only` `:2548-2570` + archive re-check).
  - **Eval-coverage** splits — **missing owner_role field** hard-raises (`:1877-1879`); **missing
    dev/regression eval** is only a **blocking DoR question** (`:1854-1864`) because `build_candidate_pack`
    does **not** hard-gate DoR (`archive.py:1573-1610`). F1 asserts the blocking question, not a package
    refusal. New residual gap **R2** records the absent DoR package-gate.

### 6. Two-artifact runtime model — resolved
- **Was:** "pinned requirements **or** vendored wheels in the bundle" (unresolved).
- **Now (`CONTRACT_RUNTIME.md §1-3`, `CONTRACT_SKILL_BUNDLE.md §3`):** **Artifact A** = a separately
  installed, **exact-version** `owak` runtime (engine + client + transports + hash-pinned deps); **Artifact
  B** = a **thin, portable** skill bundle that carries **no wheels and no engine**, only declaring the exact
  runtime version it needs. The clean-environment test installs A, then runs the loop from B against it.

### 7. `AuthorityTransportError` → `E_AUTHORITY_UNAVAILABLE` survival mechanism defined
- **Now (`CONTRACT_IPC_WIRE.md §5`):** `AuthorityTransportError` derives from a fresh `AuthorityClientError`
  base and is **not** a subclass of any type the kernel/adapter already catch (`AuthoringError`,
  `WorkspaceError`, `ArchiveError`, `AuthorizationError`, `ValidationError`, `OSError`, `_Adapter*Error`).
  `build_candidate_pack`/`build_workspace_archive` catch only `(AuthoringError, WorkspaceError)`
  (`archive.py:1609`, `:1569`) so it passes through; P3.1 audits all provider-call sites for a catch-all and
  adds a narrow re-raise where needed; `AdapterSession.execute`/`execute_json` gain an
  `except AuthorityClientError → E_AUTHORITY_UNAVAILABLE` arm **before** the generic arms (`adapters.py:636`,
  `:642`); `AdapterErrorCode` gains the code. Test: transport failure on **every** verb → the code, never
  mislabelled/uncaught.

### 8. HTTPS production transport is future / out of P3
- **Now:** P3.1 implements the **authenticated local IPC** target only (named-pipe/UDS). HTTPS + enterprise
  auth is **future**, marked out of P3 in `CONTRACT_AUTHORITY.md §1/§5` and `CONTRACT_IPC_WIRE.md §2`.

### 9. Skill archive format/version/manifest/verifier; generic ZIP, no candidate validation
- **Was:** `CONTRACT_SKILL_BUNDLE.md §1` reused `_validate_candidate_document` on the bundle.
- **Now (`CONTRACT_SKILL_BUNDLE.md §1/§1.1`):** the skill bundle is a **new third `ArchiveFormat`**
  `"ontowiz-skill-bundle"` (`format_version: 1`), built from the **generic** deterministic ZIP spine
  (`_build`/`_base_manifest`/`_entry`/`verify_archive` + portable-path + canonical JSON + collision/byte
  guards) with its **own manifest** (host, entry table, shared-core digests, required runtime version) and
  **own verifier**. Candidate-document validation (`_validate_candidate_document` `:1292`,
  `_validate_candidate_inventory` `:1450`, gated to `ontowiz-candidate-pack`) is **not** applied to a skill
  bundle.

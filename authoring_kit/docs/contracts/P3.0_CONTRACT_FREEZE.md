## 2. Two protocols — do not conflate them

The freeze governs two **distinct** wire surfaces. Neither ever carries trust material in-band.

| Protocol | Endpoints | Status | Where |
|---|---|---|---|
| **Adapter protocol** | `owak` CLI ⇄ `AdapterSession` kernel (in-process) | **EXISTS** at `0b0245c` | `adapters.py` — `AdapterRequest`/`AdapterResponse`, `:177`/`:250` |
| **Authority wire protocol** | `AuthorityHostClient` (keyless) ⇄ external authority host | **TO BUILD** (P3.1) | `CONTRACT_IPC_WIRE.md` |

- The **adapter protocol** is content-bounded (`_MAX_REQUEST_BYTES = 1_048_576`, `adapters.py:50`),
  strictly discriminated (`adapters.py:163-174`), rejects duplicate keys (`:285`) and non-finite JSON
  constants (`:281`), and emits deterministic NFC-normalised JSON (`adapter_response_bytes`, `:307`).
  **Credentials are deliberately out-of-band** (`AdapterRequest` docstring, `:178`).
- The **authority wire protocol** is new. It reuses the adapter protocol's envelope discipline
  (versioned, length-bounded, strict, redacted, duplicate-key/non-finite rejection, canonical JSON) but
  carries the `AuthoringTrustProvider` method calls (§3) and the credential-issuance exchange, over a
  transport the drafting agent cannot subvert.

## 3. Decision log (authority-review decisions incorporated by this freeze)

Each row is a decision the freeze pins. `Supersedes:` rows change a prior r2 statement and are declared
here so no decision changes silently.

- **D1 — Client name & posture.** The out-of-process authority proxy is named **`AuthorityHostClient`**.
  It is **keyless**: it holds no signing key, no credential-minting secret, and no authority high-water
  state; it authenticates to the host and forwards protocol calls over **authenticated local IPC**
  (named-pipe on Windows / UDS on POSIX). **HTTPS is future, out of P3** (correction #8); P3.1 implements the
  local IPC target only.
  `Supersedes: P3_REVISED_MINISPEC.md §1 name "AuthorityHostProxy" — renamed per GO; posture unchanged.`

- **D2 — Authority surface = the real 9-method Protocol.** The frozen provider surface is the actual
  `AuthoringTrustProvider` Protocol at `authoring.py:408-463` (**nine** methods, §CONTRACT_AUTHORITY §2),
  plus the out-of-band credential-issuance exchange (`AuthoringIntent` → `OperationCredential`, verified
  by `authenticate_actor`, `authoring.py:417`). `attest_journal`/`verify_journal` are **not** Protocol
  methods at `0b0245c` and are **removed** from the frozen surface.
  `Supersedes: P3_REVISED_MINISPEC.md §1 method list — prose listed attest_journal/verify_journal and a standalone prepare_intent provider method; the real Protocol has neither. Code wins.`

- **D3 — Two CLI verbs added.** `owak update-session` and `owak withdraw-source` are frozen into the CLI
  surface. Both are already kernel operations (`AdapterOperation` includes `update_session` and
  `withdraw_source`, `adapters.py:81-91`; `UpdateSessionCommand` `:141`, `WithdrawSourceCommand` `:149`;
  engine `update_session_state` `authoring.py:1452`, `withdraw_source` `:1004`) — the CLI merely exposes
  them. No new kernel op required for these two.

- **D4 — `owak checkpoint` needs one new kernel op.** `owak checkpoint` emits a real `.owworkspace`
  through a **new read-only, provider-converged `export_workspace` `AdapterOperation`** that converges on
  `build_workspace_archive` (`archive.py:1508`). This op does **not** exist at `0b0245c`
  (`AdapterOperation`, `adapters.py:81-91`, has no `export_workspace`) — it is the **only** new adapter
  operation P3 introduces, and the CLI must not call private archive helpers.

- **D5 — Codex-first, Claude-second, byte-parity.** `owak skill build --host {codex|claude}` emits a
  deterministic bundle per host; **Codex is primary (built and validated first); Claude is second**; both
  wrap **one byte-identical shared core**. Grounded in the existing dual adapter surface
  (`adapters/codex/skills/ontowiz-authoring/`, `adapters/claude/CLAUDE.md`; `CLAUDE.md` already asserts
  "identical to Codex").
  `Supersedes: P3_REVISED_MINISPEC.md §5.1 host token "{claude|openai}" — frozen as "{codex|claude}" to match adapter dir names, with Codex-first ordering.`

- **D6 — New stable error `E_AUTHORITY_UNAVAILABLE`.** Distinct from `E_AUTHORIZATION` (reachable host
  refused, `adapters.py:95`). Raised when the host is unprovisioned/unreachable (config missing, server
  pin mismatch, transport down, timeout), surfaced from a typed `AuthorityTransportError` at the
  IPC/config layer, redacted like every adapter error.

- **D7 — Signoile is logical-complete + binding-ready only.** The P3.4 demo authors a fictional obesity
  **pricing** candidate pack whose every metric carries price-type (list/net/reimbursed), market +
  jurisdiction, population/cohort, time-window + freshness, inputs, grain, missing/conflict behaviour,
  abstention, evidence, and owner — with **no invented SQL, joins, or physical table/column names.**
  OKF / Ossie / `DataBindingProfile` / Snowflake are **out of P3** (§5).

- **D8 — Two-artifact runtime; deps pinned in the runtime, not the bundle.** Python floor `>=3.11`
  (`pyproject.toml:9`; the repo pins only floors today — `cryptography>=42.0 / jsonschema>=4.22 /
  pydantic>=2.0 / PyYAML>=6.0`, `pyproject.toml:10-15`). P3 ships **two artifacts**: a separately installed,
  **exact-version** `owak` runtime (engine + deps) and a **thin portable skill bundle** that carries no
  wheels or engine and only declares the runtime version it needs. A clean-environment acceptance test
  installs the runtime, then runs the loop from the thin bundle. See `CONTRACT_RUNTIME.md` (correction #6).

## 6a. Shared readiness gate — R2 is an in-scope F1 defect, not future work (correction #1)

R2 (the old "package does not hard-gate DoR") is **closed by F1**, not deferred. F1 freezes **one shared
readiness gate** — a single predicate that **reuses** the existing `compile_questions` blocking-question
computation (`_compile_questions_under_lock`, `authoring.py:1796-1901`); **no parallel validator** is added.
Frozen behaviour:

- **`resume` MAY report blockers** — it surfaces the blocking questions in its snapshot and does **not**
  fail.
- **`checkpoint` MAY preserve an incomplete workspace** — `build_workspace_archive` (`archive.py:1508`) is
  a snapshot of in-progress state and is **exempt** from the gate.
- **`validate` MUST fail while any blocking question remains** — the gate is applied by `validate_authoring`.
- **`package` MUST fail while any blocking question remains** — the gate is applied by
  `build_candidate_pack`.
- **Every `DecisionContract` must carry linked `dev` *and* `regression` evaluation coverage** — part of the
  blocking predicate (reuses / extends the eval-linkage in `compile_questions`, `authoring.py:1854-1900`,
  incl. `required_context` linkage `:1866-1872`).

One gate, two doors (`validate` + `package`), reusing one existing DoR compiler; `resume`/`checkpoint`
exempt. F1 proves it **before** the Signoile demo.

**Binding clarification (authority, at the P3.0-grant / P3.1-start).** The readiness gate **must not** make
`AdapterSession._snapshot` or `resume` fail — `resume` returns the blocking questions and `checkpoint`
preserves an incomplete workspace. The gate is therefore applied **only** to (a) the `validate` **command
path** and (b) candidate **package** construction (`build_candidate_pack`), through **one shared readiness
function** (or an explicit `require_ready` mode) — **never** inside `validate_authoring`/`_snapshot`, which
`resume` calls. Recorded here (on `build/P3.1`) so F1 implements it exactly.

## 7. Boundary — actual material, not words

The boundary check (Gate 6) detects **actual protected material** in the built skill and any profile: no
vault files, no protected held-out cases/answers/rubrics/mappings, no private receipts, no keys or
credentials **as data/structure**. **Documentation may mention** "credential", "vault", or "held-out" —
prose keywords are not violations. **Public `dev`/`regression` eval cases are allowed**; only protected
held-out cases/answers/rubrics and private receipts stay inaccessible (the agent may read counts/coverage
only). This extends `tests/evaluation/test_evaluation_repository_boundary.py` to the built bundle. The
skill inherits the `.owpack` exclusion contract in full (`CONTRACT_SKILL_BUNDLE.md §4`).

## 4. Freeze-time corrections (please verify against the tree)

1. `AuthoringTrustProvider` has **nine** methods (`authoring.py:411,414,417,426,433,439,445,451,457`) — no
   `attest_journal`/`verify_journal`. `prepare_intent` is a **kernel** method (`adapters.py:375`), not a
   provider method. Credential issuance is out-of-band (`AuthoringIntent` → `OperationCredential`, verified
   by `authenticate_actor`).
2. `update_session` / `withdraw_source` are **already** adapter ops (`adapters.py:81-91`, command models
   `:141`,`:149`) — the GO's "new verbs" are new **CLI** surface only.
3. `export_workspace` is **genuinely new** — no such adapter op exists; `build_workspace_archive`
   (`archive.py:1508`) exists but is unreachable from the CLI. One new op bridges them.
4. Host token frozen `{codex|claude}` (adapter dirs `adapters/codex/**`, `adapters/claude/**`), not r2's
   `{claude|openai}`.

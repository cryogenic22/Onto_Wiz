## 10. Note for INT — the `globals.css` source-scope change
D0.1's build was green at submission, but Tailwind v4 auto-detects content **from the
git root** and crawls the whole monorepo. Non-frontend files that appeared/grew after
D0.1 (the v2 spec `.md`s, the Prototype 9 HTML) now make an unscoped build **crash**
(`RangeError: Invalid code point …` in `markUsedVariable`). D0.2 adds
`@import 'tailwindcss' source('../')` so Tailwind only scans `frontend/src`. This
**also retroactively hardens D0.1's build** against the enlarged repo. When D0.1+D0.2
are merged in order, the tree builds clean.

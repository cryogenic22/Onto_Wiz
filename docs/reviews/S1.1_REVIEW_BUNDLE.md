## 2. What the unit delivers (the claim under review)

The compiler emits a **byte-identical, reproducibly digest-addressed candidate
regardless of input order, working directory, or wall-clock time**, written
**fresh** (nothing removed upstream survives on disk), carrying an **exact input +
output inventory**, with an empty compile produced but **flagged non-releasable**.
It introduces **manifest v2** and a reusable `verify_candidate_dir` that S1.2 will
reuse at load time on untrusted packs.

**Critical gate (§11):** determinism — **T1a, T1b, T1c must pass**. A
non-byte-identical candidate is a §17 stop condition for the whole platform.

## 8. Reviewer falsification focus (where to attack)

If you have limited time, attack these — they are where a false "green" would hurt
most:

- **Determinism is real, not digest-only.** T1a asserts **full-directory
  byte-equality**, not just equal `candidate_digest`. Confirm the assertion walks
  files+bytes, not only the digest field.
- **The seal is non-self-referential.** §5.2/§5.3: `candidate_digest` reads
  payload digests out of `output_inventory` (no re-hash, excludes itself);
  `pack.sig` covers `pack.yaml` but not `pack.sig`. Confirm there is no cycle.
- **`verify_candidate_dir` is safe on hostile input** (finding #1) — this is the
  code S1.2 will point at untrusted packs. Try to construct an inventory path the
  grammar admits but that escapes the candidate.
- **No volatile field reaches candidate bytes** (amend-2). Confirm `compiled_at`,
  `evals`, `coverage`, `freshness_days`, `signed` are stripped on write.
- **Concurrency create-or-fail** (T5d/T5e): confirm promote is atomic
  `os.rename` and the loser re-enters the idempotency/conflict branch — no
  partial directory is observable.

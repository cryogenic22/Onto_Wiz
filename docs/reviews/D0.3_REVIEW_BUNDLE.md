## 6. Accessibility (WCAG 2.2 AA, §13)
- **Colour is never the sole signal.** The identifying *text* is always rendered — the
  attribution name, the provenance locator, the layer label — while avatars and
  source/warning icons are decorative (`aria-hidden`), so greyscale / colour-blind
  readers lose nothing. Test-enforced across all layers and sources.
- **Links are real links.** `href` renders a native `<a>` (keyboard-focusable, visible
  `focus-visible` cyan ring); no `div`+`onClick` faux-links. Test-enforced.
- **Long names/locators are responsive.** Name/locator sit in a bounded flex child
  (`min-w-0 … truncate`) exposing the full value via `title`; chips `flex-wrap` in their
  row — no horizontal overflow at 360px. Truncation + `title` are test-enforced.
- Foundry-token tones match Prototype 9 `.chip`/`.chip.src`/`.chip.unval`/`.tag`/`.av`.
- **Outstanding shared-FE-DoD item (carried, same as D0.1/D0.2):** 360/768/1440 live
  screenshots. Responsive behaviour is responsive-by-construction (flex-wrap + truncate)
  and test-enforced; live capture via the local browser path has been environmentally
  unreliable in this repo (documented in D0.1/D0.2). INT can capture during REV, or the
  production `next build` render can be inspected on `/ui`.

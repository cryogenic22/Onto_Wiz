## 6. Accessibility (WCAG 2.2 AA, §13)
- **Focus always visible** — every interactive primitive has a `focus-visible` cyan ring
  (2.4.7). Modal manages initial + return focus and closes on Escape.
- **Error is icon-free but never colour-only** — `aria-invalid` + `aria-describedby` +
  visible message text, so the invalid state is conveyed to AT and greyscale, not by the
  ember border alone (1.4.1). Test-enforced.
- **Dialog semantics** — `role="dialog"`, `aria-modal`, `aria-labelledby` the title.
- **No legacy palette** — Foundry tokens only; test-asserted across primitives.
- **Outstanding shared-FE-DoD item (carried, same as D0.1–D0.3):** 360/768/1440 live
  screenshots. Layout is responsive-by-construction (`flex-wrap`, `sm:grid-cols-3`, bounded
  `max-w-*`) and demoed in `/ui`; local browser capture remains environmentally unreliable
  (documented D0.1–D0.3). INT can capture during REV against the production `next build`.

# D0.4 — Existing primitives on Foundry tokens (FE Loop 0) · §12.1 mini-spec

**Lane:** FE (builder) · **Loop:** 0 · **Unit DoD (§13):** *no nested-card regressions;
focus / error / disabled states.* · **Source of truth:** the reviewed D0.1 Foundry tokens
(`src/ui/tokens.*`) + Prototype 9's operational density.

## 1. Objective and user-observable outcome
Rebase the seven ported legacy primitives (`components/ui/`) off their legacy Tailwind
palette (`blue-*`, `slate-*`, `red-*`, `amber-*`, `emerald-*`) and the two-mode persona
density system onto the **single Foundry design system** — so they are adoption-ready for
D1.1 and the control-plane rebase (per `DESIGN_SYSTEM_CONVERGENCE_2026-07.md` §C). Each
primitive gains explicit **focus-visible / error / disabled** states and renders in `/ui`
as a "Primitives" section on Foundry tokens. **Anti-bloat:** the dead `Badge.tsx` (a
colour-only subset of D0.2 `LifecycleBadge`) is deleted, not recoloured.

## 2. Preconditions and pinned contracts
- D0.1 tokens exist (`src/ui/tokens.*`); this unit **stacks on D0.3** review SHA `59029aa`
  (chain `5f2a4b5 → 8263575 → 5af28b1 → 59029aa → D0.4`). Consumes tokens + `cn` only.
- **Zero-consumer / zero-regression fact (verified by grep):** nothing imports these
  primitives and there are no `<Button>`/`<Card>`/`<Input>`/`<Textarea>`/`<Modal>`/
  `<ProgressDots>` usages in `src`; `Badge` has zero JSX usages. The "no nested-card
  regressions" DoD is therefore satisfied by construction here and demonstrated in `/ui`.
- **Persona scope:** only these 4 primitives consumed `var(--persona-*)` (grep-verified).
  D0.4 retires those density vars from `globals.css`; `lib/persona.ts` (the mode hook) and
  the two dashboards that call `usePersona()` are **untouched** (they use the mode string,
  not the density vars).
- Dep `lucide-react@^0.563` (already approved) supplies the Modal close icon.

## 4. API / events / schema changes
No backend/OpenAPI/DB impact. Component API (additive; no breaking change — and zero
consumers regardless):
```ts
type ButtonVariant = 'primary' | 'secondary' | 'ghost' | 'danger';   // unchanged
interface CardProps   { variant?: 'default' | 'inset'; className?; children }   // + variant
interface InputProps    extends InputHTMLAttributes    { label?; error?: string }  // + error

// Modal / ProgressDots: same props; Modal gains dialog semantics internally.
```

## 5. State machine and invariants
Presentational; drive no domain transitions (Tier-A read-only, R1). Invariants:
- (a) **Foundry-only palette.** No legacy `slate-*`/`blue-*`/`red-*`/`amber-*`/`emerald-*`
  class survives; colours come from Foundry tokens (`cyan`/`molten`/`jade`/`ember`/`info`/
  `iris`, surfaces `void`/`carbon`/`slab*`, borders `edge*`, text `ink*`).
- (b) **Focus is always visible** — every interactive primitive has a `focus-visible` cyan
  ring (keyboard-navigable, WCAG 2.2 AA 2.4.7).
- (c) **Error is not colour-only** — `error` sets `aria-invalid`, links a message via
  `aria-describedby`, and renders the message text (colour + text + ARIA).
- (d) **Disabled** is visually and interactively inert (`disabled` attr + reduced opacity).
- (e) **Nested cards stay distinct** — `inset` renders a lighter surface so a Card-in-Card
  reads as nested, not doubled.
- (f) **Modal is a dialog** — `role="dialog"`, `aria-modal`, `aria-labelledby` the title;
  Escape + overlay-click close; focus moves in on open and returns to the opener on close.
Forbidden: colour-only error/state; removing keyboard focus; re-introducing a second badge.

## 6. Threat and data-egress delta
None. Presentational; no network/auth/storage/model. Modal renders caller-supplied children
only. Deleting `Badge` removes code; no data path.

## 8. Migration, rollback, recovery
No data migration. Rollback = `git revert` the file edits + restore `Badge.tsx` from history.
Persona density-var removal is reversible from `globals.css` history. Coverage-include change
is additive.

## 9. Telemetry / operational failure behaviour
None (presentational). Unknown Button variant is unreachable via the TS union; a defensive
default falls back to `primary` styling rather than rendering unstyled.

## 10. Out of scope / residual risk
- New primitives (Select, Tabs/Segmented, SectionHeader) — later units per convergence §D.
- Full modal focus-**trap** robustness (cycling within the dialog) is shared with D0.7 Drawer;
  D0.4 ships dialog role/aria + initial/return focus + Escape, not an exhaustive trap.
- The two dashboards still call `usePersona()` for mode; their own rebase is a later unit.
- No consumer is wired onto these primitives yet (adoption is D1.1 / the control-plane rebase).

## 11. Dependency change
None new. Uses already-approved `lucide-react`.
